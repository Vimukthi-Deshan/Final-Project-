# Grading Data

## Files

- `real_alba_c5.csv`: real-company track data for Track 1 model training/validation.
- `synthetic_c4_mexico_hamburg.csv`: synthetic, spec-derived data for Track 2 generalization test only.

## Integrity Rules

- Track 1 metrics are the only real-data validation metrics.
- Track 2 must always be reported as `generalization test`.
- Do not present Track 2 outcomes as real-world accuracy.
